## Release procedure (every sprint end, D-035/D-039/D-040)

1. PR `sprint-N → staging` (merge commit) → Vercel staging deploy → smoke.
2. PR `staging → main` (merge commit) → Vercel production deployment.
3. `db-migrate.yml` auto-applies new migrations to the target (D-050) — verify via the job log, not just "it ran".
4. Prod smoke; record version + date here. **Flipping a kill-switch flag is a separate, deliberate step** — a merge going live does not itself turn anything on (everything ships dark by default, D-018).
